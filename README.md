# Washington LVT message test, takeaways (web version)

Served at https://progress-and-poverty-institute.github.io/wa-lvt-message-test/, the digital copy of the one-page takeaways sheet. It is password-protected until the
sheet is released: the public page is a password box and one encrypted file, and the sheet and its PDF are
inside the encrypted file.

Everything here is generated by `tools/build_main_study_one_pager.py --web` in the private repository
`washington-state-message-testing`. The page is built from the same markup, numbers and checks as the
printed PDF, so the two cannot disagree. Do not edit these files: change the source there and republish.
